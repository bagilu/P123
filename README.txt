P123 參數式空間建模 V0.3.0
============================

版本定位
本版是矩形房間與矩形開口的第一個參數式建模版本。使用者以固定公分單位輸入房間寬、長、高，並可在四面牆上加入門、窗或一般開口。3D 模型會依有效參數重建。

使用方式
1. 解壓縮 ZIP，確認外層資料夾名稱為 P123_ParametricRoomBuilder_V0.3.0。
2. 使用 Chrome、Edge 或 Firefox 開啟 index.html；第一次載入 Three.js 需要網際網路。
3. 預設建立 300 × 400 × 300 cm 的矩形房間，對應 A001、A002、A003。
4. 在左側選取 W001–W004 的任一牆面，選擇門、窗或一般開口，再按「加到選取的牆面」。
5. 每一開口會自動取得 O 編號與四個 A 參數：寬度、高度、左距、下距。
6. 在右側修改公分數值；有效數值會更新 3D，無效數值會顯示原因並保留最後一次有效模型。
7. 可下載目前 JSON，之後再由「開啟 JSON」恢復編輯；也可匯出 GLB。
8. 「範例檔案」提供可編輯的含門窗參數式房間，並保留 V0.2.1 的空房間、引導式房間與雙房間範例（唯讀檢視）。

編號規則
- R001：房間物件。
- W001–W004：前、右、後、左牆。
- O001 起：門窗或一般開口。
- A001–A003：房間寬、長、高。
- 每個開口依序新增四個 A 編號，分別為寬、高、左距、下距。
- 「左距」以人在室內面向該牆時的左側為基準。

限制
- V0.3.0 只提供矩形地板模板與矩形開口。
- L 型地板、家具、門扇方向、窗框、照片辨識與自動比例尺不在本版範圍。
- 舊版與複合空間 JSON 可檢視與匯出，但不會轉成可編輯參數。
- JSON 是主要資料；GLB 是衍生模型，尺寸標示不會成為 GLB 的原生尺寸物件。

主要檔案
- index.html：應用程式入口。
- app.js：參數、驗證、3D 重建、JSON／GLB 匯出。
- styles.css：三欄式介面與響應式樣式。
- sample-models.js：舊版範例的內嵌備援。
- config-sample.js：公開設定範例；本版無任何密鑰。
- data/：範例 JSON。
- docs/P123-SPACE-0.2.0.md：資料格式說明。
- docs/SDS-v3.6-Compliance.md：SBI-P-SDS v3.6 遵循與測試報告。
